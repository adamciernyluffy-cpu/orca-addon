# Orca Client — Minecraft 26.3

A Fabric client starter with an ocean/orca themed GUI.

## Build on GitHub

1. Upload this whole project to a GitHub repository.
2. Open **Actions**.
3. Select **Build Orca Client**.
4. Click **Run workflow**.
5. When it finishes, download the `orca-client-26.3` artifact.

GitHub Actions installs Java 25 and Gradle 9.6 automatically.

## Local Windows build

Java 25 is required.

Run:

    gradlew.bat build

The generated JAR will be in:

    build/libs/

## Open GUI

Press **Right Shift** in Minecraft.
